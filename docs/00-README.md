## Cara Pakai

- **Untuk kerja harian:** buka `09-roadmap-2-minggu.md`.
- **Untuk laporan ke pembina tiap minggu:** salin isi `10-weekly-report-template.md`, isi,
  lampirkan bersama `11-project-status-dan-definition-of-done.md` (tabel status ter-update).
- **Kalau ada perubahan scope/keputusan baru:** jangan diam-diam dikerjakan — catat dulu di
  `12-changelog-dan-notes.md` supaya ada jejak, baru kerjakan.
- **Kalau lupa kenapa suatu fitur divalidasi begitu:** cek `04-business-flow-dan-rules.md`.
